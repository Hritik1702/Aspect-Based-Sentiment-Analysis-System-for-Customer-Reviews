# Aspect-Based Sentiment Analysis System for Customer Reviews

This project implements an end-to-end **Sentiment Analysis and Aspect-Based Sentiment Analysis (ABSA)** system using **Natural Language Processing (NLP)** and **Machine Learning**.  
The system analyzes customer reviews to determine both **overall sentiment** and **aspect-level sentiment** (e.g., food, service, price, ambience), providing interpretable and actionable insights.

---

## Project Overview

Customer reviews contain valuable feedback, but analyzing them manually at scale is inefficient.  
This project addresses that challenge by:

- Classifying reviews as **Positive or Negative**
- Extracting **aspect-specific opinions**
- Providing explainable sentiment insights for business decision-making

The project is designed to be **academically rigorous**, **industry-aligned**, and **portfolio-ready** for Master’s-level students.

---

## Objectives

- Perform sentiment classification on real-world customer reviews  
- Apply NLP preprocessing techniques to clean and normalize text  
- Use TF-IDF for feature extraction  
- Train a supervised machine learning model for sentiment prediction  
- Extend sentiment analysis to the **aspect level** using rule-based NLP  
- Produce interpretable outputs suitable for business analysis
